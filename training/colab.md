# Training on Colab

Open [`colab.ipynb`](colab.ipynb) directly in Colab — the notebook has the steps
and the expected results:

https://colab.research.google.com/github/eren-o23/arxiv-classifier-api/blob/main/training/colab.ipynb

Set the runtime to a **T4 GPU** and add an `HF_TOKEN` secret with write access
before running it.
